# Platform Admin Guide

## 1. Role Studio & User Management
Navigate to `/admin/roles` to manage roles, assign action permissions, and configure department data scopes for enterprise users.

## 2. Feature Flags & Configuration
Navigate to `/monitoring` or invoke `/api/v1/admin/features` to toggle platform features (e.g. `FEATURE_PROXY_BIDDING`, `FEATURE_SEALED_BIDDING`).

## 3. KYC & Seller Approval Queues
Navigate to `/admin/kyc` to view pending seller and bidder onboarding submissions, inspect document attachments, and record approval/rejection reviews.
