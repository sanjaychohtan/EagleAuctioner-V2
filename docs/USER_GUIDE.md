# Platform User Guide

## 1. Registration & KYC Onboarding
1. Sign up as a Bidder or Seller.
2. Complete KYC verification by uploading government ID and business registration documents.
3. Track KYC approval status on the onboarding dashboard (`/onboarding`).

## 2. Participating in Live Bidding
1. Navigate to `/auctions` and select an active auction lot.
2. Ensure wallet balance meets minimum EMD requirements (`/finance/wallet`).
3. Submit manual bids or enable Proxy Bidding with a maximum limit (`/auctions/{id}/lots/{lotId}/bid`).
